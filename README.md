# PhotoTimeFixer

修复安卓（特别是小米 MIUI/HyperOS）相册「照片显示时间异常」的小工具。

## 背景问题

通过数据线拷贝、小米互传等方式把照片/视频传到手机上后，在相册「全部照片」里显示的时间会变成**传输那一刻**，而不是真实的拍摄时间；但点进详情又能看到正确的拍摄时间。

原因：安卓系统媒体库（MediaStore）里有三个时间字段——

| 字段 | 含义 | 能否被第三方 App 修改 |
| :--- | :--- | :--- |
| `date_modified` | 文件修改时间（相册排序用这个） | ✅ 可改 |
| `date_taken` | 拍摄时间（来自 EXIF） | ❌ 系统只读，但可通过「重新扫描」重建 |
| `date_added` | 添加到媒体库的时间 | ❌ 系统只读（不影响相册排序） |

相册「按日期分组」用 `date_taken`，「同一天内排序」用 `date_modified`（文件修改时间）。

## 本项目包含两部分

### 1. 安卓 App（修复照片）

**目录**：`app/`，包名 `com.sirandev.phototimefixer`

**功能**：
- 自动扫描相册全部照片，把「文件时间 ≠ 拍摄时间」的照片标红识别；
- 阈值可调（1 分钟 / 10 分钟 / 1 小时 / 1 天）；
- 支持手动多选，也可以「全选异常」一键勾选；
- 点击缩略图跳转到相册对应照片；
- 一键修复：把文件时间改回拍摄时间，并触发系统重新扫描重建拍摄时间。

**权限**：
- `READ_MEDIA_IMAGES`（Android 13+）/ `READ_EXTERNAL_STORAGE`（Android 12 及以下）：读取照片列表；
- `MANAGE_EXTERNAL_STORAGE`（所有文件访问权限）：修改照片文件时间。Android 11+ 需在系统设置中手动授予。

**说明**：
- 照片的「显示时间异常」——无论跨天（分到错误的日期）还是同一天内（顺序错位）——都可以修复；
- 处理完成后建议**重新打开相册**（或下拉刷新），排序才会立即更新；
- 视频**不在本 App 处理范围内**，请用下面的脚本。

### 2. 视频时间脚本（电脑端）

**目录**：`video_time_fixer/`（含 `set_video_time.py`、`设置视频时间.bat`、`tools/exiftool.exe`）

**用途**：把脚本所在文件夹（含子文件夹）下所有视频文件的**文件时间**统一改为各自的**拍摄时间**。

**用法**：
1. 把 `video_time_fixer/` 整个文件夹（脚本 + bat + tools）复制到视频所在文件夹；
2. 双击 `设置视频时间.bat`；
3. 处理完成后，把整个文件夹重新导入手机（复制或 adb push 都会保留文件时间），相册会按拍摄时间重新分组。

**依赖**：ExifTool（已内置在 `video_time_fixer/tools/`，脚本会自动查找）。

> 视频脚本修改的是「文件修改时间」，重新导入后相册会按拍摄时间正确分组；处理完成后同样建议重新打开相册刷新。

## 构建

```bash
# 环境：Android Studio（JDK 21+，Android SDK 37）
./gradlew assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```
